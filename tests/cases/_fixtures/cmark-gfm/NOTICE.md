# cmark-gfm fixture attribution

The generated `cases.json` contains test inputs and expected HTML derived from
[`test/spec.txt`](https://github.com/github/cmark-gfm/blob/587a12bb54d95ac37241377e6ddc93ea0e45439b/test/spec.txt)
and
[`test/extensions.txt`](https://github.com/github/cmark-gfm/blob/587a12bb54d95ac37241377e6ddc93ea0e45439b/test/extensions.txt)
in GitHub's cmark-gfm repository, version 0.29.0.gfm.13 (702 examples total).

[Creative Commons Attribution-ShareAlike 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
cmark-gfm is maintained by GitHub, Inc. and cmark-gfm contributors.

Supramark converts the upstream fenced examples to a unified JSON representation,
normalizes line endings to LF, and replaces the visible tab marker with tab characters.
Markdown inputs and expected HTML are otherwise unchanged.

The exact source repository, commit, fixture path, and normalized source hash are recorded in `version.json`.
