# CommonMark fixture attribution

The generated `cases.json` contains test inputs and expected HTML derived from the
[CommonMark Specification](https://github.com/commonmark/commonmark-spec), version 0.31.2,
by John MacFarlane and CommonMark contributors.

The specification content is licensed under
[Creative Commons Attribution-ShareAlike 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
Supramark converts the upstream fenced examples to a unified JSON representation, normalizes line
endings to LF, and replaces the specification's visible tab marker with tab characters. Markdown
inputs and expected HTML are otherwise unchanged.

The exact source repository, commit, fixture path, and normalized source hash are recorded in
`version.json`.
